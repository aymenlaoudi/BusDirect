# BusDirect
 
Petit projet pour gérer les réservations de sièges d'un bus **Safi → Marrakech** (20 places).
 
## Ce que l'application fait
 
- Voir le plan du bus (siège libre en vert, siège occupé en blanc)
- Réserver une place avec le nom du passager
- Modifier une réservation (nom ou siège)
- Supprimer une réservation
- Le nom est obligatoire et on ne peut pas avoir 2 fois le même nom
- Un message apparaît après chaque action
- Voir le nombre de places libres et la recette (80 DH par place)
- Les données restent après actualisation (localStorage)
- Site responsive (PC et mobile)

## Technologies
 
- HTML
- Tailwind CSS
- JavaScript
